## Repository structure

- `Highway_Trucks_Reboot/` — active mod project.
- `Pacific_Trucks_Rebirth/` — active mod project.
- `Padara_tweaks/` — active mod project.
- `Templates/` — reusable starting points; do not alter unless explicitly requested.
- `Test/` — experimental or temporary work; do not assume its contents are production-ready.
- `Depreciated/` — archived/deprecated work; do not modify unless explicitly requested.

## Change guidelines

- Keep changes scoped to the requested mod or file.
- Do not perform unrelated cleanup, formatting, renaming, or refactoring.
- Preserve existing folder names, mod IDs, asset paths, and file formats unless the task explicitly requires changing them.
- Check the surrounding files and existing conventions before adding new content.
- Avoid changing archived, template, or test content unless the request specifically targets it.
- Keep backups before making broad changes to mod assets or configuration files.

## Validation

- When relevant, document compatibility, dependencies, known limitations, and version-specific changes.

## Repository policy

This is a personal mod repository. Do not introduce unrelated features or broad repository-wide changes. External pull requests are not part of the normal workflow.
